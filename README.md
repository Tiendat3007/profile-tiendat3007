# ✨ Phạm Huỳnh Tiến Đạt — Personal Portfolio

Website hồ sơ cá nhân của **Phạm Huỳnh Tiến Đạt** (30/07/2006) — sinh viên ngành **Công nghệ Thông tin**, Học viện Công nghệ Bưu chính Viễn thông (**PTIT**).

Theme **"Lacquer & Gold"** — sắc đỏ sơn mài và vàng kim, lấy cảm hứng từ văn hoá Việt, kết hợp phong cách công nghệ hiện đại.

## 🚀 Tính năng

- 🎬 Preloader & hiệu ứng xuất hiện tên theo từng dòng
- 🌌 Nền particle constellation (Canvas) phản hồi theo chuột
- 🖱️ Con trỏ tuỳ chỉnh, nút "nam châm", thẻ 3D tilt & spotlight
- ⌨️ Hiệu ứng gõ chữ vai trò + terminal tự gõ lệnh giới thiệu
- 🎂 Tự tính tuổi, năm học và đếm ngược sinh nhật theo thời gian thực
- 📊 Vòng tròn kỹ năng (SVG), bộ lọc kỹ năng & dự án
- 🧭 Timeline hành trình với thanh tiến trình theo cuộn trang
- ✉️ Form liên hệ mở sẵn email, sao chép email nhanh + toast
- 📱 Responsive hoàn toàn, hỗ trợ `prefers-reduced-motion`

## ✏️ Chỉnh thông tin

Thông tin động (email, GitHub, năm nhập học, vai trò...) nằm trong object `CONFIG` ở đầu file `script.js`.

## 💻 Chạy thử

```bash
node server.js
```

Truy cập: `http://localhost:8080`
